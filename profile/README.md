# Sakura Network

Mais do que um servidor, a Sakura é uma rede construída em torno do Minecraft, com uma comunidade própria, diferentes modos de jogo e uma identidade que vai além de cada partida.

**Minecraft Java Edition · 1.8.8 — 26.3**
